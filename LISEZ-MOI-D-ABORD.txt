Dovozo clients

Ouvrir index.html pour utiliser le CRM local. Le fichier démarre vide et conserve les données déjà stockées dans le navigateur sur la même adresse.

Sauvegarder régulièrement depuis Paramètres > Export JSON. L'import est validé et demande une confirmation avant restauration.

Le dépôt GitHub est public et le CRM est accessible en ligne : https://addictshoppeuse.github.io/crm-client/. Le dépôt ne contient aucune donnée réelle et son historique est propre depuis l'origine (un seul commit initial, rien d'importé).
